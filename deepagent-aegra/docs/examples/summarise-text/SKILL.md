---
name: summarise-text
description: Summarise an uploaded text file in a chosen style and save the summary as a file
---
Read the `document` file and summarise it in the style given by `fields.style`
("bullets" = at most 5 bullet points, "paragraph" = one short paragraph, "tweet" = under 280 characters).
Write the summary to a .txt file named `summary.txt` and mention it in your reply.
