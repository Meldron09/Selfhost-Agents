# Pointer-shaped Attachment/Output state fields, discovered via post-run state fetch

File references (both uploaded Attachments and generated Outputs) travel as custom, pointer-shaped LangGraph state fields — `attachments`/`outputs`: `list[{key, filename}]` — declared via `create_deep_agent(state_schema=...)`, not as deepagents' built-in `files: dict[str, FileData]` channel from `FilesystemMiddleware`. `files` is content-shaped: it holds raw file bytes/text directly in Postgres-checkpointed state, which bloats every checkpoint regardless of file size, whereas local disk (managed by a new upload/download HTTP app) is already this project's source of truth for file bytes. Confirmed by source-level research (deepagents `graph.py`'s `state_schema=` merge logic) that a custom field like this flows opaquely through aegra's `POST /threads/{id}/runs` `input` dict and forwards automatically into subagents via the `task` tool.

`agent-chat-ui` discovers an Output's value via a guaranteed post-run `GET /threads/{id}/state` call, not by parsing the orchestrator's chat reply or by relying on live `stream_mode=values` events. Confirmed by source-level fact-check (`aegra_api`'s `ThreadStateService.convert_snapshot_to_thread_state`) that this endpoint returns the full, unfiltered state dict with no field allowlist. Rejected relying on the stream instead, because it would require verifying and possibly changing `agent-chat-ui`'s current `stream_mode` request configuration — an unverified client-side dependency — for no benefit, since a download link only matters once the file is fully written anyway.

Both fields are lists rather than single objects, for multi-file support: `agent-chat-ui`'s upload UI is already being widened to allow multiple files per run, and `output-writer`'s tools could plausibly emit more than one artifact in a single run.

Resolved while working wayfinder ticket [Decide: file-reference wire contract (upload → run input, output → download link)](https://github.com/Meldron09/Selfhost-Agents/issues/3), grounded in prior research on [Research: can the deepagents state schema carry a structured attachments field?](https://github.com/Meldron09/Selfhost-Agents/issues/2).
